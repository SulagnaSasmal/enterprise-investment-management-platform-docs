SunGard Asset Arena Manager

High availability & 24×7 server model
WebLogic clustering, Oracle RAC, and DR design

Objective

Enable a 24×7 Asset Arena application server that remains available during NAV calculation and fund accounting batch windows, while preserving correctness for date-sensitive operations and Oracle Coherence cache coherence.

Architecture Summary

  • Active/active WebLogic cluster behind F5 load balancer with session affinity
  • Oracle RAC (2+ nodes) for database-level redundancy with automatic instance failover
  • Oracle Data Guard physical standby at DR site with real-time redo log shipping
  • Rolling restart strategy for WebLogic nodes to apply patches without full outage
  • Coherence cache federation for cross-data-center cache replication

Business Date Rollover (D → D+1)

Date rollover in Asset Arena is a coordinated lifecycle event triggered by the Asset Arena Scheduler based on fund domicile zone calendars. All WebLogic nodes must advance atomically.

Order Eligibility Cleanup at Rollover

  • Re-evaluate pending orders with date constraints (valid-from/valid-until, market calendar rules).
  • Expire GTC/GTD orders that fall outside D+1 calendar boundaries.
  • Regenerate settlement date projections using D+1 market calendars (T+1, T+2 rules).
  • Write auditable lifecycle updates for every order state change triggered by rollover.

WebLogic Rolling Restart Procedure

  • Drain node via F5 health check disable → complete all inflight EJB transactions → graceful shutdown.
  • Apply patch or configuration change to the stopped node.
  • Restart node, verify Coherence cache re-join and Oracle connection pool health.
  • Re-enable in F5 load balancer after health check passes (AAIM heartbeat endpoint).
  • Repeat for each remaining node in the cluster.

Disaster Recovery

  • RPO target: <15 minutes (Oracle Data Guard synchronous redo shipping)
  • RTO target: <4 hours (automated failover for Oracle; manual WebLogic bring-up at DR)
  • DR testing: quarterly DR failover exercises with NAV calculation validation
  • Cache warm-up: Coherence near-cache pre-load scripts run during DR activation
Quarterly DR tests include end-to-end NAV calculation for a sample fund set to validate data integrity across Oracle Data Guard switchover and Coherence cache re-synchronization.
