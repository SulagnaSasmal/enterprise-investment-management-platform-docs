Platform documentation overview

This documentation covers the architecture, operational procedures, and release governance for SunBridge Asset Atrium Manager (now FGS Asset Atrium) — an enterprise investment management platform used by asset managers, hedge funds, insurance companies, pension funds, and fund administrators globally.

Platform scope: Asset Atrium Manager encompasses the Investment Manager (ATIM), Settlement Manager, and Fund Administrator modules. This documentation focuses on platform-level architecture, batch processing, high availability, and release operations.

Platform context

What Asset Atrium Manager does

  • Manages the institutional trade lifecycle: order capture → compliance check → route → execute → allocate → settle
  • Runs post-trade processing via batch and event-driven frameworks (NAV calculation, pricing, fund accounting)
  • Maintains positions, cash, holdings, and portfolio analytics across multi-entity, multi-currency structures
  • Operates globally across APAC, EMEA, and Americas market calendars and processing zones
  • Supports equities, fixed income, derivatives (OTC & listed), FX, alternatives, and structured products

What this documentation covers

  • J2EE application server architecture with WebLogic clustering and Oracle RAC
  • 24×7 application server model with controlled date rollover and cache lifecycle
  • NAV calculation batch orchestration: dependencies, idempotency, zone segmentation
  • Failover design with per-event transactional guarantees and JMS retry policies
  • Release impact governance: ops readiness, backward compatibility, and risk framing

Key platform capabilities

  • Multi-entity / multi-GAAP accounting — IFRS, US GAAP, and local GAAP simultaneously
  • Zero-downtime batch model — 24×7 server availability during NAV and EOD batch windows
  • Global time zone processing — portfolio-to-zone association with zone-based NAV cut-off times
  • SWIFT & FIX integration — MT5xx settlement instructions and FIX 4.2/4.4 order routing
  • Bloomberg & Reuters market data — real-time and EOD pricing via Bloomberg BVAL and Refinitiv
